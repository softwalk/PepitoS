# OpenSpec — extracto en el repo

La especificación completa (OpenSpec v2) vive fuera del repo en `version3/Sistema/PEPITO_OS_OpenSpec_v2/openspec/`.
Aquí se versionan sólo los artefactos que nacen con cambios de código, para que spec y código viajen juntos:

- `specs/reports/spec.md` — requisitos normativos del módulo de Reportes (BI).
- `changes/002-reportes-bi/` — proposal, design y tasks del cambio que lo implementó.

La trazabilidad requisito → código está en `docs/TRAZABILIDAD_OPENSPEC.md`.
